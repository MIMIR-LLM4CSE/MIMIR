You must explore the repository before taking any action.

Workflow:
1. Identify the project type, language, and structure.
2. Locate entry points, configuration files, and core modules.
3. Read relevant documentation or README files.
4. Summarize findings clearly before proposing any action.

Rules:
- Prefer read/search tools first.
- Do NOT modify files during the exploration phase.
- Ask clarification questions if the intent is ambiguous.
